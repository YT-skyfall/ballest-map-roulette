# Changelog

User-facing changes for Map Roulette are documented below.

## 0.1.8 — Initial release (October 2026)

- Redesigned the search screen with a prominent Workshop search field and **MORE FILTERS**.
- Moved advanced filter controls to a dedicated screen.
- Added **RESET FILTERS** while preserving music, effects, and auto-open settings.
- Polished reel presentation with clearer visual focus on the current thumbnail.
- Simplified the winner display to emphasize the map thumbnail, map name, and **PLAY THIS MAP**.
- Fixed Workshop search, include/exclude tags, and author-time text inputs so clicking FIND MAPS uses the values currently typed, without requiring Enter (creator-tested).
- Kept search-based map selection, auto-opening, music, audio effects, and known author-time behavior.
- Retained the author-time limitation for maps that have not previously been checked.

This version includes the search-and-tag input fix verified in-game, the finalized interface, and the documented author-time limitation.

## 0.1.5 — Last previously confirmed stable baseline

- Search Workshop maps with text, sort, tags, rating, play count, and unfinished-only options.
- Animated five-thumbnail roulette, real map images, manual or automatic open.
- Music, spinning ticks, and reveal sounds.
- Experimental author-time filter for already checked map revisions.

The exact earlier development version history is intentionally not reproduced here.
